这是这个网站的第一篇文章，也是整套写作工作流的第一次实战。

## 为什么搭这个站

之前一直想有个地方能稳定地放自己的文字和作品，试过不少平台，要么被推荐算法绑架，要么排版不受控制。最后决定自己搭一个：**内容是 Markdown 文件，躺在自己的 git 仓库里**——不依赖任何平台的存活。

## 这套工作流

写作在 Obsidian 里完成，保存的瞬间文件就落在本仓库的 `src/content/blog/` 目录。然后在 Obsidian 里按下 `Ctrl/Cmd + P`，搜 `Commit and push`，文章就被推送到 GitHub，触发自动构建和部署。

> 写完即发布，中间没有任何"导出""复制粘贴"的环节。

## Markdown 能力示范

这里顺便测试一下各种排版元素：

**加粗**、*斜体*、`行内代码`、~~删除线~~，还有[外部链接](https://github.com/zhangqier94-cyber)。

列表也支持：

1. 有序列表第一项
2. 有序列表第二项

- 无序列表 A
- 无序列表 B

表格：

| 能力 | 支持情况 |
|---|---|
| 标题层级 | ✅ h2 ~ h4 自动生成文章目录 |
| 代码块 | ✅ 高亮渲染 |
| 图片 | ✅ 存 `attachments/` 自动复制 |
| 引用块 | ✅ 就像这样 |

代码块长这样：

```js
function hello() {
  console.log("Hello, FLH.LIFE");
}
```
